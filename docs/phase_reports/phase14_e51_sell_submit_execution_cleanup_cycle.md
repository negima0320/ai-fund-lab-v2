## Root Cause

The SELL cleanup cycle is blocked at:

```text
SELL Pending -> Submit preflight guard
```

Specific guard reason:

```text
estimated amount exceeds max order amount
```

This guard currently blocks SELL liquidation orders whose estimated notional exceeds the max order amount limit. Since the order never reaches the Broker adapter, the issue is not a Tachibana Demo acceptance/reject issue.

- If it applies to SELL, define whether SELL cleanup should split orders, reduce quantity, or stop for manual review.
- If it should not block Runtime-owned position liquidation, revise the guard contract in the normal Runtime submit path, not via a Phase14 or Demo-only bypass.
- Keep Pending-only Submit, Approval, duplicate guard, Production guard, and Current quantity guard unchanged.
