## 9. どの年が強かったか

最も強かったのは2024年。

```text
年間収益率 +837.3%
年間利益 245,201,160円
```

2022年と2023年も強い。

```text
2022年 +535.2%
2023年 +245.3%
```

2026年は弱い。

```text
年間収益率 -5.5%
DD -25.7%
```

2026年の特徴。

```text
大きな勝ちトレードもあったが、
大型損失トレードが複数発生し、年単位ではマイナスになった。
Phase8では2026型の弱い相場を検知する補助policyが必要。
```

なぜ勝てたか。

```text
Phase5 Opportunity Top3の選別力が強かった。
CAP5により高回転を抑えつつ、強い候補への入替を残せた。
利益を再投資する複利効果が大きかった。
```

## 10. Phase7結論

採用候補。

```text
Primary:

POLICY_Y_CAP4_EDGE08_CONF5
```

CAP5を採用候補にする理由。

```text
利益が大きい
高回転すぎない
30bps/30bpsのコスト条件でもReferenceを上回る
Phase8で検証する価値が最も高い
```

主なリスク。

```text
最大DDは約-33.6%
2026年はマイナス
実取引では税・スプレッド・部分約定・売買停止・値幅制限がある
今回の検証はまだPaper Tradingではない
```

実運用で注意すること。

```text
いきなり実売買しない
Paper Tradingで30営業日以上確認する
売却約定前に買付しない
買付余力を毎回Brokerから再取得する
CAP5だけでなくCAP4とPOLICY_Yを比較監視する
```
