## 13. ユーザー向け要約

大きく勝った銘柄は、大東港運、ジャパンディスプレイ、木徳神糧、川西倉庫、山一電機。業種では電気機器、倉庫・運輸関連が強かった。

大きく負けた銘柄は、トーシンホールディングス、インバウンドテック、ＲＥＶＯＬＵＴＩＯＮ、ビーマップ、ソレイジア・ファーマ。損失側は情報通信・サービス、グロース市場、短期で急落した小型寄りの銘柄が目立つ。

強かった年は2024年、2022年、2023年。弱かった年は2026年で、Phase6から見えていた weak-regime 問題が継続している。

資金は平均82.1%使われており、ほとんどの期間で現金を寝かせすぎてはいない。ただし2026年は資金利用率が下がり、相場環境悪化時の買い控え・候補不足・損失抑制ロジックの検証が必要。

Phase8では、実運用制約として約定遅延、部分約定、値幅制限、売買停止、スリッページ、税金、銘柄名マスタの時点差を必ず確認する。特にグロース市場と情報通信・サービス系は、勝ちも負けも大きいため監視対象にする。
