# Phase6-J Random Yearly E2E Smoke Test

## 1. Purpose

Phase6-J verifies the Phase4 to Phase6 buy-candidate flow end to end:

```text
Phase4 Candidate AI
-> Candidate Top50
-> Phase5 Opportunity AI
-> Opportunity Top5
-> buy decision smoke check
-> future outcome check for evaluation only
```

This is a smoke test, not a performance evaluation or trading simulation.

## 9. Limitations

- Candidate AI was not retrained or regenerated from raw all-symbol data during this smoke test.
- The test uses the precomputed Phase4 historical Candidate Top50 artifact.
- Opportunity AI is formally re-scored with the Phase5 model.
- Future outcome columns are evaluation-only.
- This is not a full backtest and does not simulate trades, position sizing, allocation, broker calls, or orders.
